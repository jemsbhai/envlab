# Dewin brand

- `logo/`: the Dewin logo pack. `dewin-logo-dark` is for dark backgrounds, `dewin-logo-light` for light ones, `dewin-logo-transparent` has no background. `dewin-icon` is the app icon mark.
- `splash/`: the app splash, the wordmark centered on navy `#0B0F1A`, 1290 × 2796 (iPhone portrait). The SVG is the source; the PNG is rendered from it with `rsvg-convert`.

Colors: navy `#0B0F1A`, aqua `#5EEAD4`, sky `#BAE6FD`, teal `#0D9488`, text `#F2F4F7`.
